Privacy Policy

Last updated: 24 October 2026

Rebecca is a personal assistant used only by its owner, for the owner's own Google account. It has no other users.

What data Rebecca accesses

With the owner's permission, Rebecca reads the owner's Gmail messages, Google Calendar events and Google Tasks, and can create Gmail drafts, calendar events and tasks for the owner.

How the data is used

The data is used only to send the owner reminders and summaries on WhatsApp and to carry out the owner's own requests. It is not used for advertising, it is not sold, and it is not shared with anyone else.

Where the data is stored

Rebecca runs on the owner's own computer. Sign-in tokens and reminders are stored only on that computer. Email, calendar and task content is fetched when needed and is not kept.

Google API Services

Rebecca's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove Rebecca's access at any time at https://myaccount.google.com/permissions.
